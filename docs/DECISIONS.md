# Architecture & Implementation Decisions

Recorded decisions where specs offered alternatives, flagged ambiguities, or interacted with host/runtime realities.

## Phase 0 — Bootstrap

### 1. TypeScript Schema Adjustments (`T0.2`)

- **`Insight.explanation` shape**: Typed as `{ short: string; deep: string }` across `packages/shared-types/src/diagnosis.ts` to align `04-DATA-MODEL.md` (which commented "short + deep versions") with `13-NETWORKING-REACHABILITY.md` and `17-DIAGNOSIS-AND-CHALLENGES.md`.
- **Optional `NetworkConfig` arrays**: Made the top-level arrays on `NetworkConfig` (`networks`, `subnets`, `routeTables`, etc.) optional so the minimal design example in `04-DATA-MODEL.md` (`"network": {}`) validates directly against `packages/shared-types/schemas/design.schema.json`. Added `createEmptyNetworkConfig()` helper for normalized access.
- **Complete union variants**: Added `'cache-flush'` to `ChaosEvent` (`05-SIMULATION-ENGINE.md` §7), `'compartment'` to `GroupInstance.kind` (`10-CATALOG-OCI.md` / `16-UI-UX-SPEC.md`), and `runtimePreset`, `ai`, `storageGb`, `scannedBytes`, `scenarioOverrides`, `prefixes`, `cancelOnTimeout`, `connectionWaitMs`, and `writeLatencyMultiplier` fields to `NodeConfig` (`05`, `06`, `07`, `11`, `14`).
- **JSON Schema generation**: `ts-json-schema-generator` omits `config.path` and reads `tsconfig.fileNames` so all `packages/shared-types/src/**/*.ts` definitions resolve without `TS6307`.

### 2. Containerized Laravel Dev Server (`T0.3`)

- **PHP built-in server in container entrypoint**: `php artisan serve` filters container environment variables through its internal `ServeCommand` whitelist and can fall back to `.env` defaults (`DB_CONNECTION=sqlite` in host files). `apps/api/docker-entrypoint.sh` therefore runs `cd /var/www/html/public && exec php -S 0.0.0.0:8000 ../vendor/laravel/framework/src/Illuminate/Foundation/resources/server.php` after Postgres and Redis pass healthchecks and `php artisan migrate --force` succeeds.
- **Stateless Sanctum Bearer tokens on `/api/*`**: Disabled `$middleware->statefulApi()` so browser requests from `http://localhost:3000` / `http://127.0.0.1:3000` using `Authorization: Bearer <token>` (without cookies) never hit Laravel's `419 CSRF token mismatch` middleware on `/api/auth/register` or `/api/auth/login`.
- **SQLite `:memory:` for fast PHPUnit runs**: `apps/api/phpunit.xml` targets SQLite `:memory:` so unit/feature suites execute in <1 s offline; live Postgres 16 + Redis 7 compatibility is verified via Docker Compose and CI migrations.
- **Docker build DNS note**: Hosts running local `systemd-resolved` stubs (`127.0.0.53`) may require `docker build --network=host -t infrasim-api:local ./apps/api` prior to `docker compose up -d` unless Docker daemon DNS is configured globally.

### 3. Frontend Stack, Visual System, and Icons (`T0.4`)

- **Tailwind CSS v3.4 + CSS custom properties**: Pinned Tailwind v3.4 (`tailwindcss@3.4`, `postcss`, `autoprefixer`) paired with Graphite dark (`#0f0f10`–`#232325`) and light (`#f4f4f5`–`#ffffff`) CSS custom properties in `packages/ui-kit/src/styles.css`. Avoids Tailwind v4 config churn with monorepo workspace transpile packages while keeping theming deterministic.
- **Self-hosted offline fonts**: Bundled `@fontsource/ibm-plex-sans` and `@fontsource/jetbrains-mono` in `apps/web` instead of remote font CDNs so offline runs and Playwright tests remain deterministic and zero-latency.
- **Own-drawn & Lucide icon policy (`16-UI-UX-SPEC.md` §12)**: InfraSim originally used custom geometric SVGs (`LogoMark`, kind glyphs) and `lucide-react` 16 px stroke icons alongside provider badge chips (`AWS`, `GCP`, `Azure`, `OCI`, `Generic`, `Custom`); superseded for the 243 cloud provider services by **Decision #7** below (`generic.*` and `custom` retain Lucide kind icons).
- **Reduced motion exemption class**: Global `@media (prefers-reduced-motion: reduce)` excludes `.infrasim-motion-safe` so overloaded nodes replace horizontal shaking with a non-translating pulsing outline while disabling movement animations across the UI.
- **Next.js typecheck in CI**: `apps/web/package.json` runs `next typegen && tsc -p tsconfig.json --noEmit` so `pnpm typecheck` passes cleanly even before `next build`, and `eslint.config.mjs` / `.prettierignore` ignore auto-generated `apps/web/next-env.d.ts`.

### 4. Architecture & Library Choices (`03-ARCHITECTURE.md`)

- **Pure-package ESLint guardrails**: `eslint.config.mjs` enforces that `sim-engine`, `network-analyzer`, `cost-engine`, `diagnosis`, and `terraform` never import `react`, `next`, `node:*`, Node standard modules, or browser globals (`window`, `document`, `localStorage`). `sim-engine` also forbids `Math.random()`, `Date.now()`, and `new Date()` outside test files.
- **Worker communication (`Comlink`)**: Dedicated Web Workers (`sim.worker` and `sandbox.worker`) use `comlink` for typed RPC, with frame updates throttled to `<= 10` frames/s real time and `AbortSignal` / run-ID cancellation within 200 ms.
- **Sandbox runtime (`QuickJS-WASM`)**: Phase 3 executes user JS/TS inside `quickjs-emscripten` inside `sandbox.worker` (bundled with `esbuild-wasm`) rather than `isolated-vm` (requires native V8 addons on server) or host `vm`/`eval`, preserving zero-credential browser execution and deterministic virtual time.
- **Charts & auto-layout choices (logged upfront for Phase 1 / Phase 5)**:
  - **Charts**: Lightweight custom SVG time-series charts with LTTB decimation (`<= 500` points) in Phase 1 (or Recharts if complex multi-axis tooltips become needed), minimizing First Load JS within the 400 KB gzip workbench budget.
  - **Auto-layout**: `elkjs` planned for nested Region/VPC/AZ/Subnet containers and Terraform import graph layout (Phase 5), since `dagre` does not natively support compound nested groups cleanly.

## Phase 1 — Canvas + Core Simulation (MVP)

### 5. Catalog Build Pipeline & Equivalents (`T1.1`)

- **Dual build output (JSON + static TypeScript)**: `scripts/build-catalog.ts` emits normalized per-provider files in `packages/catalog/data/{aws,gcp,azure,oci,generic,index}.json` **and** `packages/catalog/src/generated/catalogData.ts` so browser bundles, Next.js client components, Vitest, and Web Workers import `@infrasim/catalog` without runtime filesystem reads or JSON import assertions. `pnpm catalog:check` verifies both artifacts match `docs/specs/07-10` and `packages/catalog/defaults/*`.
- **Category heading cleanup**: Normalized Markdown `### AI & ML (mocked — see file 11)` headings to `"AI & ML"` in the generated catalog so palette grouping stays concise and uniform across providers.
- **PostgreSQL equivalence on OCI**: Mapped PostgreSQL services (`aws.rds_postgres`, `gcp.cloud_sql_postgres`, `azure.postgres_flexible`) directly to `oci.postgres` present in `docs/specs/10-CATALOG-OCI.md` (while `aws.rds_mysql`, `gcp.cloud_sql_mysql`, and `azure.mysql_flexible` map to `oci.mysql_heatwave`), updating the earlier starter note in `06-SERVICE-CATALOG-SPEC.md` §8 which listed `oci.mysql_heatwave (closest)`.

### 6. DES Engine Frame Integration & Phase 1 Scope (`T1.5–T1.11`)

- **Continuous-time integrated frame utilization (`emitSimFrame`)**: Sub-second UI animation frames (`SimFrame`) compute frame-window utilization from cumulative continuous-time integrals (`slotBusyAreaMs`, `coreBusyAreaMs`, `connBusyAreaMs`) blended with the 1-second EMA smoothed state rather than point-sampling `busyCores / activeCores` on tick instants. `health` transitions remain anchored to the 1-second hysteresis tracker (`evaluateNodeHealthStep`) plus active frame drops (`frameDrops > 0`) or zero active instances (`'down'`), preventing healthy 1–2 core nodes at 70–75% load from flashing spurious red `overloaded` frames on single-millisecond occupancy overlaps.
- **Lazy timeout heap pruning (`inTimeoutHeap`)**: `AttemptToken` tracks explicit heap membership (`inTimeoutHeap`) so long-horizon edge timeouts (`deadlineMs >= endMs`) that are skipped at enqueue time never decrement `activeTimeoutCount` below zero and trigger redundant `O(n² log n)` heap compactions under high-concurrency DB/cache bypass loads.
- **Phase 1 rule-based diagnosis subset (`@infrasim/diagnosis`)**: Implemented core Phase 1 bottleneck detection rules (CPU/thread-pool saturation, DB pool exhaustion, overload cascades) with deterministic JSON Patch fixes and automated Why? before/after verification (`T1.9–T1.10`) inside `@infrasim/diagnosis`; the full 50+ rule library, challenge scorer, and share links remain scheduled for Phase 6 (`T6.1–T6.8`).

### 7. Per-Service Vendor Icon Assets & Usage Terms (`T1.12`)

- **License & terms review (`16-UI-UX-SPEC.md` §12 update)**: Per explicit user request to display real service icons across AWS (77), GCP (53), Azure (63), and OCI (50), reviewed cloud vendor diagramming usage guidelines (AWS Architecture Icons, Google Cloud Icons, Microsoft Azure Architecture Icons, Oracle Cloud Infrastructure Diagramming Toolkit): all four providers permit bundling architecture icons to depict cloud services in interactive architecture diagrams provided icon artwork/colors remain unaltered, adjacent service text labels are shown, and non-affiliation trademark attribution is maintained.
- **Bundled static SVGs (`apps/web/public/icons/services/`)**: Extracted and sanitized 228 unique static SVG files (414.5 KiB total) covering all **243** provider services in `@infrasim/catalog` from MIT-licensed `cloud-icons@0.3.0` / `@thesvg/icons@4.0.4` (AWS, GCP, Azure) and UPL-1.0 `oracle/oci-designer-toolkit` (OCI OKIT/OCD), keeping `generic.*` (`8` blocks) and `custom` services on the 1.5-stroke `lucide-react` kind icons. Attributions live in `apps/web/public/icons/services/ATTRIBUTIONS.md`.
- **`<img>` isolation instead of inline `<svg>`**: Rendering each static SVG via `<img draggable={false} decoding="async" />` in `ServiceIcon` isolates duplicate internal `<defs>` gradient IDs (`prefix__a`) and `<style>` classes (`.st0`/`.st1`) across sibling canvas nodes/palette items, adds 0 KB to the JS bundle, and preserves native icon proportions via `object-contain`.

### 8. Canvas Wire Animation, Edge Label Clearance, and Dark Controls/MiniMap (`T1.13`)

- **Single high-DPI canvas overlay (`EdgeParticlesOverlay`) instead of SVG `<animateMotion>`**: Updating `dur` on SMIL `<animateMotion>` every 100 ms when edge RPS changed during live simulation batches/playback reset Chromium's animation clock and forced full-graph React re-renders. Replaced SMIL particles with a single `ViewportPortal` `<canvas>` overlay running an independent 60 fps `requestAnimationFrame` phase loop with smooth velocity easing, synchronized synchronously with React Flow viewport transforms, while decoupling `ServiceNode` and `InfraEdge` frame updates via `CanvasSimStateContext` (`liveNodes`/`flowEdges` rebuild only on topology/selection edits).
- **Tight-gap edge label clearance (`computeEdgeLabelPlacement`)**: Raised `.react-flow__edgelabel-renderer` (`z-index: 20`) above `ServiceNode` (`zIndex: 10`), increased default starter template horizontal gaps to `136 px` (`16 px`-grid aligned), and lifted horizontal tight-gap edge badges above the card band with a hairline stem whenever two connected cards sit closer than the pill width.
- **Dark-mode React Flow Controls, MiniMap, and Attribution + Topbar clearance**: Synced `<ReactFlow colorMode={theme}>`, passed explicit Graphite tokens to `<MiniMap>`, and raised CSS selector specificity (`[data-theme='dark'] .react-flow`) in `apps/web/src/app/globals.css` so `@xyflow/react/dist/style.css` defaults never override Graphite surface/text colors regardless of Next.js stylesheet chunk ordering; constrained topbar flex shrinking in `EditorShell` so left scenario selectors never overlap center run controls across `1280px`–`1440px+` viewports.

## Phase 2 — Full Catalog, Mock Editing, Cost

### 9. Verified Public Pricing APIs & Snapshot Publishing (`T2.6`)

- **AWS Price List Bulk API (`https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/index.json`)**: Verified 273 live offer codes and their exact casing: Step Functions is `AmazonStates`, Keyspaces is `AmazonMCS`, OpenSearch Service is `AmazonES`, Comprehend is `comprehend`, Transcribe is `transcribe`, Translate is `translate`, KMS is `awskms`, WAF is `awswaf`, while `AWSAppRunner`, `AmazonMQ`, `AmazonDAX`, `AmazonMemoryDB`, `AmazonTimestream`, `AmazonSageMaker`, `AmazonBedrock`, `AmazonBedrockService`, and `AmazonBedrockFoundationModels` use their exact offer keys. Confirmed `aws.batch` and `aws.beanstalk` have no standalone billing offer codes (control-plane orchestration is free; underlying EC2/Fargate/EBS resources carry the cost) and recorded them under `knownUnavailable` in `packages/cost-engine/data/price_sku_map.json`.
- **Azure Retail Prices API (`https://prices.azure.com/api/retail/prices?api-version=2023-01-01-preview`)**: Verified `priceType eq 'Consumption'` OData filtering, `NextPageLink` pagination, `tierMinimumUnits`, and current official `serviceName` values (Azure Functions is `'Functions'`, Container Instances is `'Container Instances'`, SignalR is `'SignalR'`, Azure OpenAI / AI Vision / Speech / Translator / Document Intelligence / Language / Content Safety are published under `'Foundry Models'` and `'Foundry Tools'`, AI Search is `'Azure Cognitive Search'`, NAT Gateway is `'NAT Gateway'`, Private Link / VNet Peering are under `'Virtual Network'`, and egress transfers are under `'Bandwidth'`). Case-insensitive filtering removes `Spot`, `Low Priority`, and `Windows` across `productName`, `skuName`, and `meterName`, as well as `Reservation`/`SavingsPlan` items. Confirmed `azure.batch` (free orchestration over VMs/Storage) and `azure.communication_email` (no standalone Email serviceName in the Retail Prices catalog) under `knownUnavailable`.
- **GCP & OCI verification ahead of `T2.7`**: Confirmed `https://cloudbilling.googleapis.com/v1/services` requires a billing API key (`GCP_BILLING_API_KEY`, returning HTTP 403 unauthenticated) with tiered rates in `units + nanos / 1e9`; confirmed `https://apexapps.oracle.com/pls/apex/cetools/api/v1/products/` returns unauthenticated JSON with global list prices (`currencyCodeLocalizations[].prices[]` where `model === 'PAY_AS_YOU_GO'`, normalized under `region: 'global'`).
- **Atomic Snapshot Publishing & Offline Fixture Mode**: `price_snapshots.status` transitions `'staging' -> 'published'` inside a database transaction (archiving prior `'published'` snapshots for the same provider), keeping prior published prices untouched on upstream failures. `prices:sync --file=<path>` accepts recorded JSON fixtures so CI and offline environments test AWS and Azure normalization, idempotent `raw_hash` skipping, rollback, and alert thresholds deterministically with zero live cloud calls.

### 10. GCP/OCI Price Normalization, VCN Transfer Rules, and Curated Instance Specs (`T2.7`)

- **GCP Billing Catalog API (`GcpPricingFetcher`)**: Normalized `tieredRates[]` pricing using exact decimal arithmetic (`units + nanos / 1e9`) and adjusted progressive tier thresholds proportionally when scaling per-unit rates to per-million (`1M Requests`). Compute Engine and GKE VM SKUs split into separate `vcpu_hour` and `memory_gb_hour` rows per machine family, while Compute Engine general internet egress matches `"Network Internet Egress"` SKUs (versus `"Download Worldwide Destinations"` which Cloud Billing places under Cloud Storage).
- **OCI Cost Estimator Products API (`OciPricingFetcher`)**: Normalized unauthenticated `PAY_AS_YOU_GO` USD tiers under `region: 'global'` (since `apexapps.oracle.com/pls/apex/cetools/api/v1/products/` publishes uniform global list rates), mapping sentinel `rangeMax >= 900000000` (`999999999` / `999999999999999`) to unbounded upper tiers (`null`). Documented verified `$0` VCN items from `apexapps.oracle.com`: intra-region AD-to-AD (`transfer.inter_az`), NAT Gateway (`oci.nat_gw`), and Service Gateway (`oci.service_gw`) incur `$0` service/data-processing charges, while `oci.batch`, `oci.vault_secrets`, and `oci.datascience_deployment` have no standalone paid meter and live under `knownUnavailable`.
- **Generated Static Cost Metadata (`packages/cost-engine/src/generated/costData.ts`)**: `scripts/check-price-coverage.ts` enforces 100% non-`free` catalog coverage across AWS (74), Azure (61), GCP (53), and OCI (41), emits `docs/price-coverage.md`, and generates static TS constants for `region_map.json` (10 cross-cloud regions), `instance_specs.json` (sourced vCPU/memory/arch specs), and `price_sku_map.json` so `@infrasim/cost-engine` never touches Node `fs` at runtime. Unknown custom instance types keep `vcpu`/`memoryGb` editable and prompt manual entry in `ConfigTab`.

### 11. Cost Comparison, Chaos Injection, Trace Waterfall, and Bundle Budgets (`T2.8–T2.10`)

- **Dynamic lazy-loaded inspector/modal panels with eager simulation preload (`WhyTabSlot`)**: Next.js `next/dynamic(..., { ssr: false })` wraps components in `React.forwardRef` without exposing `.preload()` and incurs async `LoadableSubscription` promise ticks even after chunk resolution. Replaced dynamic `WhyTab` with `preloadWhyTab()` + `WhyTabSlot` (triggered when `simStatus === 'running' || simStatus === 'completed'`) while keeping `ChaosTimelineEditor`, `TracesDockTab`, `CostDockTab`, and `ProviderSwitchModal` code-split so `/` First Load JS stays `<= 400 kB` and clicking an overloaded node opens `Why?` synchronously.
- **Responsive topbar & bounded `EdgePopover` (`apps/web/src/components/canvas/EdgePopover.tsx`)**: Constrained left scenario/title badges with progressive `2xl` label disclosure so centered playback controls remain unobstructed at `1280px`; constrained `EdgePopover` width/height with scroll overflow and focused newly inserted client nodes instead of leaving an overlapping edge popup across neighboring canvas nodes.
- **Synchronized `primaryRegion` on cross-cloud undo**: Added region reconciliation in `EditorShell` when `primaryProviderRegions` changes so `Ctrl+Z` undoing a GCP/Azure/OCI provider switch back to AWS restores `us-east-1` pricing rather than querying the stale target provider region.
- **Deterministic Chaos & Bounded Trace Recording (`@infrasim/sim-engine`)**: All six `ChaosEvent` variants (`add-latency`, `error-rate`, `throttle`, `kill-instances`, `az-outage`, `cache-flush`) drive the seeded PRNG and continuous-time queue/instance state inside `runSimulation`, while request traces sample up to `maxTraces = 200` full span trees with `retried`, `attempt`, `coldStart`, `timedOut`, and `zombie` span metadata for waterfall rendering.
