# Cloud Service Icon Attributions

InfraSim bundles static SVG service icons solely to identify AWS, Google Cloud, Microsoft Azure, and Oracle Cloud Infrastructure components in architecture diagrams and simulations.

- **AWS, Google Cloud & Azure icons**: sourced from `cloud-icons` (MIT License, `https://github.com/ShawnGeorge03/cloud-icons`) and `@thesvg/icons` (MIT License, `https://github.com/glincker/thesvg`), representing official cloud provider architecture icon packs.
- **Oracle Cloud Infrastructure (OCI) icons**: sourced from Oracle's official `oci-designer-toolkit` (Universal Permissive License v1.0, `https://github.com/oracle/oci-designer-toolkit`).
